# 🐾 Pet Health Diary (Daily Wellness Log)

A minimalist, soft-toned web application designed to track and monitor your beloved pets' health and daily wellness indicators. This project serves as a practical playground for mastering **Vue 3** and modern frontend development workflows.

*🎨 Features a cozy, fresh, watercolor-inspired aesthetic designed for pet lovers.*

---

## ✨ Key Features

* **Pet Profiles:** Track multiple furry friends (cats, dogs, rabbits, chicks, etc.) in one unified dashboard.
* **Wellness Tracker:** Easily log and monitor critical health metrics such as daily weight, vaccination schedules, clinical records, and medication reminders.
* **Trend Analysis:** Visual representations of health trends to keep you informed of any subtle changes over time.
* **Responsive Layout:** Clean, scannable, and intuitive UI optimized for smooth interactions.
* **Custom UI Components:** Lightweight, reusable micro-interactions and loading animations (including custom-crafted playful asset transitions).

> ⚠️ **Project Status:** **Active Development (持續更新中)** > New features, refined animations, and localized language support are being rolled out continuously.

---

## 🛠️ Tech Stack & Architecture

* **Framework:** Vue 3 (Composition API with `<script setup>`)
* **Build Tool:** Vite
* **State Management:** Pinia (planned/integrated for reactive data flow)
* **Styling:** Scoped CSS (designed with a focus on fresh, minimalist aesthetics and soft color palettes)
